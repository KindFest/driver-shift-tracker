# Описание файлов проекта (Driver Shift Tracker)

В этом документе описывается структура проекта и назначение каждого файла.

---

## 1. Исходный код приложения (Kotlin)

### [MainActivity.kt](file:///c:/MyProjects/Android/driver-shift-tracker/app/src/main/java/com/example/MainActivity.kt)
Главное и единственное Activity приложения. Реализует весь пользовательский интерфейс (UI) на основе **Jetpack Compose**:
- **Scaffold и нижняя навигация**: Переключение между вкладками (Дашборд, Смены, Отчеты, Настройки).
- **DashboardScreen**: Отображение времени начала следующей смены (с учетом обычного отдыха 11 часов и сокращенного 9 часов) разными цветами, недельный отчет, диаграммы лимитов соблюдения регламента ЕС.
- **ShiftsScreen**: Отображение журнала смен с возможностью поиска/фильтрации по датам (начало и конец диапазона), просмотр детальных данных по сменам.
- **ReportsScreen**: Позволяет выбрать период дат, сгенерировать структурированный текстовый отчет для отправки диспетчеру и быстро скопировать его в буфер обмена.
- **SettingsScreen**: Страница настроек, включающая:
  - Изменение имени водителя.
  - Переключение языка интерфейса (русский / английский) с автоматическим форматированием дат.
  - Выбор режима работы приложения: расширенный (обычная смена + тахограф) или сокращённый (вводятся только данные тахографа).
  - Справочник регламента ЕС № 561/2006 (разворачиваемый список с основными правилами и ссылкой на официальный европейский документ).
  - Раздел «О программе» с указанием номера и версии сборки.
- **ShiftFormOverlay**: Всплывающее окно добавления/редактирования смены. В сокращённом режиме скрывает поля стандартного рабочего времени.

### [MainViewModel.kt](file:///c:/MyProjects/Android/driver-shift-tracker/app/src/main/java/com/example/ui/MainViewModel.kt)
Компонент архитектурного паттерна MVVM, управляющий состоянием интерфейса и бизнес-логикой:
- Управляет состоянием активных вкладок, формами ввода и валидацией данных.
- Хранит настройки пользователя (язык, режим работы) в `SharedPreferences` и предоставляет их в виде реактивных потоков `StateFlow`.
- Реализует механизм автоматического сохранения черновика смены (`draft_work_date`, `draft_shift_start`, `draft_tacho_start`) при закрытии приложения. При повторном открытии формы данные черновика автоматически восстанавливаются.
- Проводит фильтрацию списка смен по выбранному пользователем диапазону дат.
- Рассчитывает время начала следующей смены на основе завершения тахографа последней смены.
- В сокращённом режиме копирует значения времени тахографа в поля обычной смены при отправке формы.

### [Localization.kt](file:///c:/MyProjects/Android/driver-shift-tracker/app/src/main/java/com/example/ui/Localization.kt)
Словарь локализации. Содержит переводы всех строк интерфейса и отчетов на русский (`ru`) и английский (`en`) языки, а также функции форматирования дат с учетом выбранного языка.

### [ComplianceCalculator.kt](file:///c:/MyProjects/Android/driver-shift-tracker/app/src/main/java/com/example/domain/ComplianceCalculator.kt)
Бизнес-логика соответствия регламенту ЕС № 561/2006:
- Парсинг строк времени, дат, числовых значений и денежных расходов с валидацией ввода.
- Расчет длительности смен, времени за рулем и периодов отдыха.
- Проверка нарушений ограничений:
  - Количество смен длительностью более 13 часов за неделю (максимум 3).
  - Количество дней с вождением более 9 часов за неделю (максимум 2).
  - Количество периодов сокращенного отдыха менее 11 часов (максимум 3).
  - Общий подсчет сумм расходов, часов вождения и ночёвок.

### [Database.kt](file:///c:/MyProjects/Android/driver-shift-tracker/app/src/main/java/com/example/data/Database.kt)
Описание базы данных SQLite с помощью библиотеки **Room**:
- `DriverEntity`: Таблица водителей (id, telegram_user_id, имя, дата создания).
- `ShiftEntity`: Таблица рабочих смен (id, driver_id, дата работы, начало/конец обычной смены, начало/конец тахографа, часы вождения, ночёвка в пути, расходы).
- `DriverDao` / `ShiftDao`: Интерфейсы доступа к данным с поддержкой Flow для реактивного обновления UI при изменении таблиц.

### [Repository.kt](file:///c:/MyProjects/Android/driver-shift-tracker/app/src/main/java/com/example/data/Repository.kt)
Репозиторий данных, предоставляющий единую точку доступа к БД Room и абстрагирующий логику запросов от ViewModel.

## 2. Конфигурационные файлы сборки (Gradle)

### [build.gradle.kts (App level)](file:///c:/MyProjects/Android/driver-shift-tracker/app/build.gradle.kts)
Скрипт сборки модуля приложения. Задает настройки SDK (compileSdk, targetSdk, minSdk), уникальный `applicationId`, конфигурации подписей (debug/release), используемые плагины, библиотеки (Room, Jetpack Compose, Coroutines) и версию сборки (`versionCode`, `versionName`).

### [build.gradle.kts (Project level)](file:///c:/MyProjects/Android/driver-shift-tracker/build.gradle.kts)
Корневой файл сборки проекта. Объявляет глобальные gradle-плагины, используемые в проекте.

### [settings.gradle.kts](file:///c:/MyProjects/Android/driver-shift-tracker/settings.gradle.kts)
Настройки структуры проекта. Подключает модуль `:app` и объявляет репозитории (Google, MavenCentral) для загрузки библиотек.

### [gradle.properties](file:///c:/MyProjects/Android/driver-shift-tracker/gradle.properties)
Настройки производительности компиляции Gradle, лимиты памяти JVM, параллельное выполнение задач и кэширование конфигураций.

## 3. Файлы окружения и Git

### [.env](file:///c:/MyProjects/Android/driver-shift-tracker/.env) / [.env.example](file:///c:/MyProjects/Android/driver-shift-tracker/.env.example)

Список файлов и папок, которые не должны отправляться в удаленный Git-репозиторий (локальные настройки сборки `.gradle`, скомпилированные папки `/build`, секреты `.env` и личные ключи `debug.keystore`).
